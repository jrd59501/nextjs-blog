
# Next.js Blog

A blog I built while taking the LinkedIn Learning course *Learning Next.js* by Sandy Ludosky. You can read posts, sign in with Google, and add new posts yourself or with AI.

**Live site:** https://nextjs-blog-phi-beige.vercel.app

I made a few changes from the course: I used Neon for the database, used Google's free Gemini API instead of OpenAI, and kept the AI key on the server.

## Tech
Next.js, TypeScript, Tailwind CSS, PostgreSQL (Neon), NextAuth, Gemini API, Vercel
